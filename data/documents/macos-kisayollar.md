# macOS Kısayolları

Ekran görüntüsü (belirli bölge): Cmd + Shift + 4 tuşlarına bas, sonra imleçle istediğin bölgeyi seç.

Ekran görüntüsü (tüm ekran): Cmd + Shift + 3.

Spotlight ile arama yapmak: Cmd + Boşluk.

Açık uygulamalar arasında geçiş: Cmd + Tab.

Emoji ve sembol menüsü: Cmd + Control + Boşluk.

Aktif uygulamayı zorla kapatma: Cmd + Option + Esc.
