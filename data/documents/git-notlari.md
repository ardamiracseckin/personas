# Git Notları

Son commit'i geri al ama değişiklikleri koru: git reset --soft HEAD~1.

Değişiklikleri geçici olarak sakla: git stash; geri getirmek için: git stash pop.

Yeni bir dal oluştur ve ona geç: git checkout -b yeni-dal-adi.

Yaptığın commit'leri uzak depoya gönder: git push origin dal-adi.

Commit geçmişini kısa ve tek satırlık gör: git log --oneline.

Hangi dosyaların değiştiğini gör: git status.
